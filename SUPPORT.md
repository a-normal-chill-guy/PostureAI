### Troubleshooting

**App won't open**
- Right-click the app and select "Open" (unsigned builds require this on first launch)
- Make sure you're running macOS 13.0 (Ventura) or later

**Camera not working**
- Go to System Settings → Privacy & Security → Camera
- Make sure PostureAI is enabled
- Try granting and revoking permission, then reopening the app

**AirPods not detected**
- Go to System Settings → Privacy & Security → Motion & Fitness
- Make sure PostureAI is enabled
- Ensure your AirPods are connected and compatible (Pro, Max, or 3rd gen+)

**Blur not appearing**
- Check that monitoring is enabled in the menu bar
- Recalibrate: click the PostureAI icon → Recalibrate
- Try increasing sensitivity in Settings

**High CPU usage**
- Quit and reopen PostureAI
- Check if another app is using the camera heavily

## Reporting Issues

Found a bug? Please [open an issue](https://github.com/a-normal-chill-guy/PostureAI/issues) with:

1. **What you expected to happen**
2. **What actually happened**
3. **Steps to reproduce** the problem
4. **Your setup** (macOS version, Mac model, AirPods model if applicable)
5. **Screenshots or screen recordings** if helpful
