# Contributing to PostureAI

Thank you for your interest in helping improve PostureAI! Since the source code is private, contributions are made through GitHub Issues.

## How to Contribute

### Report Bugs

Found a bug? Please [open an issue](https://github.com/a-normal-chill-guy/PostureAI/issues) with:

- A clear, descriptive title
- Steps to reproduce the issue
- Expected vs. actual behavior
- Your macOS version and hardware (Mac model, AirPods model if applicable)
- Screenshots if helpful

### Suggest Features

Have an idea? [Open an issue](https://github.com/a-normal-chill-guy/PostureAI/issues) with:

- A clear description of the feature
- Why it would be useful to you and other users
- Any implementation ideas you have

### Ask Questions

Not sure how something works? [Open an issue](https://github.com/a-normal-chill-guy/PostureAI/issues) with the question and we'll help you out.

## What Makes a Good Issue?

- **Be specific** — Clear titles and descriptions help us understand and address your feedback
- **Check first** — Search existing issues to avoid duplicates
- **One topic per issue** — Keep each issue focused on a single bug or request
- **Include details** — Your macOS version, hardware, and steps to reproduce help us fix things faster

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before participating.
